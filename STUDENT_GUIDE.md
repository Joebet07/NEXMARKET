# NEXTMARKET — First-Year Student Guide

## Start here

Open this folder in VS Code. Right-click `index.html` and choose **Open with Live Server**. Keep internet on for Bootstrap, Chart.js, icons and fonts. No npm command or database setup is required.

This version makes the central shopping logic easier to read using named functions, basic `for` loops, and `if` statements. It retains your requested features. Accounts, image resizing, and chart-library configuration are still extension topics; you do not need to understand every helper on your first day.

## The three parts of the website

**HTML** describes the content, such as headings, forms and links.

**CSS** controls the appearance, such as colors, sizes, spacing and responsive layout.

**JavaScript** responds to actions, such as searching, changing a quantity or submitting a form.

Some HTML is generated by JavaScript because the same layout must display different products. A template string uses backticks. `${value}` inserts a JavaScript value into that text. `innerHTML` puts the finished text into the page. User-provided text is passed through `esc()` before insertion, so it is treated as text rather than executable HTML.

## Follow one real example: adding to the cart

1. A product button contains `data-cart="101"`.
2. The click handler in `main.js` reads that product ID.
3. `addCart()` finds the product and checks its stock.
4. A `for` loop checks whether the cart already contains that product.
5. If it exists, its quantity increases. Otherwise, a new item is added with `push()`.
6. `write()` saves the cart, and `updateCartCount()` updates the badge.

A cart item stores an ID and a quantity. It does not copy the whole product.

```javascript
const item = { id: 101, qty: 2 };
```

## Follow the price calculation

`calculateCartTotals()` in `cart.js` starts the subtotal at zero. Each loop adds:

```javascript
subtotal = subtotal + product.price * item.qty;
```

Two ₱1,000 products give a ₱2,000 subtotal. With the sample ₱150 delivery fee, the total is ₱2,150. An empty cart has no delivery fee. The function returns an object containing the subtotal, shipping and total.

## How filters work

`filterProducts()` checks each product separately. `continue` means “skip this product and try the next one.” A product is added to the results only after passing all checks.

Multiple choices in the same category group mean **OR**. A phone can match either selected category. Different groups mean **AND**: a product must match the category, brand, condition and price rules together.

## How data stays after a reload

LocalStorage stores text. `JSON.stringify()` converts arrays and objects into text. `JSON.parse()` converts saved text back into usable data.

This is not a database shared with other users. Data belongs to the current browser and origin. Clearing browser data removes it. Login uses a session for the current tab. Different demo accounts have separate carts, favorites and orders.

## Code patterns you will also see

- `const`: a variable you will not reassign. An array stored in it can still be updated.
- `let`: a variable you may reassign, such as a running total.
- `function name()`: a reusable group of instructions.
- `return`: sends a result back or ends a function.
- `onclick` / `onchange` / `onsubmit`: functions run after a user action.
- `event.preventDefault()`: stops a form's usual page reload so JavaScript can handle it.
- `.map()` / `.filter()`: shorter ways to transform or select array items. Some display-only sections still use these.
- `value => result`: a short function, called an arrow function.
- `async` / `await`: wait for work such as image processing or password hashing.
- `try` / `catch`: handle an error, such as full browser storage.

## Advanced helpers: study later

`password-helper.js` uses the browser's password-hashing API. Do not simplify it by saving plain-text passwords. The application is still only a local demo, and browser data can be modified by its owner. Use sample emails and unique demo passwords.

Photo-upload code uses `FileReader`, `Image` and canvas to reduce image sizes. Chart.js draws the chart; your own code supplies the selected records and computes the statistics. Bootstrap handles modals and mobile offcanvas menus.

You can explain the role of these helpers without claiming you implemented cryptographic algorithms or chart rendering from scratch.

## Payment demonstration

GCash, Maya, QR, online banking and COD are selectable demo methods. No money moves. Online banking requires an example bank. The QR only contains a plain-text demo message. The selected method is saved with the demo receipt.
